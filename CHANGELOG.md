# xsai-prof releases

## 0.8.0b1 — CLI/report workflow beta, 2026-10-29

- Add NCU-style discovery aliases and consistent -o output paths.
- Resolve requested metrics/sections to shared native modes; allow explicit
  selectors with an environment config and reject unsupported target metrics.
- Add read-only dry-run plans with correctness stages, emulator invocation
  counts, target requirements and explicit unknown wall-time estimates.
- Add view and report REPORT pages, filters and text/JSON/CSV export. Keep
  missing values explicit and performance medians separate from speedup.
- Add verified report opening and readable offline memory/diagnosis views.
  Preserve asynchronous events when instruction display limits apply.
- Real collection, exact-install and browser validation are separate gates;
  see the version's acceptance report for final status. No public publication.

## 0.7.0b1 — beta, 2026-10-28

- Add reviewed AME matrix_data_in read-return sampling, source pairing and
  interface payload/service/outstanding analysis. Requires the new exact
  observer; older captures retain unknown return metrics.
- Add xsai-prof init for explicit external paths, and doctor target/coverage
  reporting with setup guidance.
- Extend unified analysis with observed memory changes, evidence coverage and
  separately labeled, falsifiable hypotheses; add AME read service timeline.
- Add offline sdist-to-wheel build receipts, CI definition, supported-target
  documentation, clean installation workflow and FA/GEMM case studies.
- Preserve separately observed diagnostics during portable import, verifying
  software/correctness images and the exact reviewed observer while retaining
  the original performance identity and its evidence limits.
- Publication is not automatic. Real RTL validation is independent of offline
  CI and packaging tests. See the version's acceptance record for final status.
